# 🌳 Unser Stammbaum

Ein privater Familien-Stammbaum, der im Browser läuft (auch am Handy).

- Personen erfassen, mit Eltern, Partnern, Kindern, Fotos, Notizen und Quellen
- Schöne Baum-Ansicht zum Verschieben und Zoomen
- Lebende Personen und alle, die jünger als 100 Jahre sind, sind geschützt 🔒
- **Alle Daten bleiben nur im Browser auf dem eigenen Gerät** – nichts davon landet in diesem Repository oder im Internet
- Sicherung als Datei sowie Austausch mit anderen Stammbaum-Programmen (GEDCOM)

Online: https://marchens1977.github.io/Stammbaum/

Reines Familienprojekt – nicht für fremde Personen gedacht.
